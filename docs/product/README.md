## 💡 Core Product Job

> **Absorb the coordination tax.** Not "AI helps you use a PM tool faster" — the AI *is* the project manager function. The software's job is to maintain an accurate, current, honest picture of the project with as little manual human bookkeeping as possible, surfacing only the decisions that require a human.
