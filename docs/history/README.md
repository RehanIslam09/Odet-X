# Immutable Historical Archive

This directory contains the historical archive for **AI Project Manager**. These records capture *how the project was built*, past audit snapshots, engineering lessons learned from incidents, and historical research specs.

---

## 🏛️ Archive Governance Rules

1. **Immutable Log Policy:** Documents in this folder are historical records. They capture point-in-time contexts and must NEVER be deleted or retroactively altered to fit current architecture.
2. **Current vs History Separation:** For active system architecture ("how it works today"), see [`docs/architecture/`](../architecture/README.md).
